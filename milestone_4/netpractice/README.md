# NetPractice

## Description

This project is an introduction to networking and system administration through a series of practical exercises. Its goal is to understand and configure small-scale networks by solving the following concepts:

- `IP addressing and subnetting`
- `Subnet masks and CIDR notation`
- `Routing tables and packet forwarding`
- `Switches and routers behavior`
- `TCP/IP protocol fundamentals`
-------

### Levels :

- `Levels 1 to 4` : Basic IP and mask configuration
- `Levels 5 to 7` : Introduction to routing
- `Levels 8 to 10` : Complex multi-router networks
-------

## Instructions

### Usage :

- Each level configuration is saved as a .cfg file
- Files are named levelX.cfg where X is the level number
